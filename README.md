An offline guide and tracker for the 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with its official name, description and grade, a guide in numbered steps with each step citing its source, a platinum roadmap, missable flags, filters, a spoiler setting, and progress saved in the browser with export and import. All 55 guides cite their sources; one trophy (Bad Luck, I Guess) is marked unconfirmed because no launch-day guide has pinned its method down yet — its guide cites the sources that say so.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. The app is plain static files under `app/` — no build step, no network at run time.
